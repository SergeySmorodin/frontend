# Создать файл .env с содержимым для продакшен зааменить на ip адрес
```VITE_API_URL=http://localhost:8000```

# Установка зависимостей
```npm install```

# Запуск в режиме разработки
```npm run dev```

# Сборка для продакшена
```npm run build```

# Предпросмотр собранного проекта
```npm run preview```
